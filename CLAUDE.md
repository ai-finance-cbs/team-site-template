# Instructions for the AI assistant

This repository is a public website for a group in B8403 Finance in the Age of AI (Columbia Business School). GitHub Pages publishes it from the main branch.

- The site is public. Never commit anything from `private/`. CVs, photos, and notes live there and stay on the laptop.
- Publish only what each team member has approved. Do not add phone numbers, home addresses, or email addresses unless a member asks for it.
- Keep the site static: HTML, CSS, JavaScript, and data files. No API keys, no live AI calls, no server, no analytics or tracking.
- `index.html` is the home page. Keep the site working when opened from the live GitHub Pages address.
- Keep images small (under 500 KB each). Resize photos before adding them.
- After each change, tell the user how to check it locally and on the live site.
